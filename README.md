### Evaluating Foundation Models for Forecasting Time Series in Public Transport: Potential and Challenges


## 🗺️ Overview

Urban mobility is a critical component for sustainable city growth, requiring efficient public transportation systems to ensure equitable access, reduce congestion, and minimize environmental impact. To address the challenges faced by traditional public transit operations, this project investigates the application of **Time Series Foundation Models (TSFMs)** for demand forecasting in urban mobility networks. Leveraging a unique and comprehensive dataset from the public transportation system of Salvador, Bahia, Brazil, we benchmark TSFMs against both classical statistical models and established neural network architectures. This repository contains the code, data processing pipelines, model implementations, and experimental results aimed at advancing the use of AI-driven approaches for optimizing public transit systems. Our work highlights the potential of TSFMs to better capture complex, dynamic patterns in urban environments and sets new benchmarks for future research in intelligent transportation forecasting.



This research uses the public transport database SUNT of the city of Salvador, Bahia, Brazil, available on [Mendeley](https://data.mendeley.com/preview/85fdtx3kr5).



## 🗂️ Repository structure


## Directory and File Descriptions

- **batch/** : Directory containing implementations, experiments, and configurations focused on `Short-Term Rolling` time series forecasting.
- **long/**  Directory containing implementations, experiments, and configurations focused on `Long-Term Static` time series forecasting.
- **results/** : Folder for storing the results generated by experiments, including evaluation metrics, plots, and analytical outputs.
- **short/** : Directory focused on implementations, experiments, and configurations for `Mid-Term Static` time series forecasting.
- **requirements.txt**: Lists all Python dependencies required to run the project, enabling easy environment setup.
